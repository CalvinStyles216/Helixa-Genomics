# Helixa Genomics — Precision Bioinformatics Landing Page

An interactive, high-performance 3D biotech landing page designed for genomic sequencing and bioinformatics data visualization.

🔗 **Live Demo:** [helixa-genomics.ai.studio](https://helixa-genomics.ai.studio)

---

## 🔬 Key Features

- **Cinematic Bioluminescent Hero:** Seamless loop video background layered with custom glassmorphism UI cards and high-contrast typography.
- **Interactive Canvas DNA Visuals:** Pure-code mathematical canvas simulations including a 3D rotating double helix, undulating chromatid arms, and resonant base-pair rings with cursor-tracking tilt and hover acceleration.
- **Responsive Layout:** Built with a modern dark/light hybrid biotech aesthetic, optimized for desktop, tablet, and mobile displays.
- **Telemetry Counters:** Smooth metric count-up animations for genomic data points and accuracy ratings.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **3D & Canvas:** [Three.js](https://threejs.org/) & HTML5 Canvas API
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Media CDN:** Cloudinary

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/CalvinStyles216/Helixa-Genomics.git

# Navigate into folder
cd Helixa-Genomics

# Install dependencies
npm install

# Start dev server
npm run dev
```
